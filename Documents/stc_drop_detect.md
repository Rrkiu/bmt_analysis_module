배드민턴 셔틀콕 낙하 위치 검출 파이프라인 개발을 위한 셜계 플랜을 다음과 같이 제안합니다.

요구사항에 따라 캘리브레이션 정밀화, 낙하 감지 알고리즘, 실세계 좌표 변환, 미니맵 시각화를 단계별 마일스톤으로 구성하였습니다.

셔틀콕 낙하 위치 검출 파이프라인 개발 계획
마일스톤 1: 코트 좌표계 고도화 및 캘리브레이션 로직 수정
목표: 사용자가 그린 4개의 점(TL, TR, BR, BL)을 실제 배드민턴 반 코트 규정에 정확히 매핑하여 왜곡 보정의 기초를 마련합니다.
상세 작업:
backend/constants.py
의 BACK_BOUNDARY_LINE(6.7m) 및 SINGLES_WIDTH(5.18m)를 기준으로 표준 실세계 좌표 정의.
사용자가 입력한 4개 지점을 실제 규격의 네 꼭짓점에 1:1 매핑하는 Homography 행렬 계산 로직 수정.
동영상 분석 시작 전 1회만 보정을 수행하도록 인터페이스 조정.
모듈: 
calibration_service.py
 내 로직 보강.

 
마일스톤 2: 셔틀콕 낙하 감지(Landing Detection) 알고리즘 구현
목표: TrackNet에서 검출된 셔틀콕의 시계열 위치 데이터를 분석하여 낙하 여부를 판단합니다.
상세 작업:
최근 N개 프레임 동안의 셔틀콕 좌표 변화량(Euclidean Distance)을 추적.
좌표 변화가 일정 임계값(Threshold) 이하로 특정 시간 동안 유지될 경우 '낙하' 상태로 전이하는 상태 머신 구현.
셔틀콕의 속도가 급격히 줄어드는지 확인하여 낙하 지점의 정확도를 높이는 로직 추가.
모듈: shuttlecock_tracker.py (신규 생성) 또는 
video_analysis_service.py
 확장.
마일스톤 3: 실세계 좌표 변환 및 낙하 위치 산출
목표: 이미지상의 (x, y) 좌표를 보정된 Homography 행렬을 통해 실제 코트 좌표로 변환합니다.
상세 작업:
낙하로 판정된 시점의 최종 픽셀 좌표를 실세계 (meter) 좌표로 변환.
변환된 좌표가 
constants.py
에 정의된 유효 코트 영역 내에 있는지 판별하는 로직 추가.
모듈: 
geometry.py
 내 변환 함수 고도화.
마일스톤 4: 미니맵 시각화 위젯 구현
목표: 분석 화면 우상단에 배드민턴 코트를 시각화하고 낙하 지점을 표시합니다.
상세 작업:
실제 규격 비율에 맞는 반 코트 미니맵 생성 로직 구현.
낙하 감지 시 미니맵 위에 해당 좌표를 점(Point)으로 시각화.
낙하 지점의 In/Out 여부를 시각적으로 구분하여 표시.
모듈: 
visualization_service.py
 내 미니맵 렌더링 기능 추가.
마일스톤 5: 백엔드 파이프라인 통합 및 최종 테스트
목표: 모든 모듈을 통합하여 "캘리브레이션 -> 분석 -> 낙하감지 -> 시각화" 흐름을 완성합니다.
상세 작업:
VideoAnalysisService
 내에서 셔틀콕 상태 추적 및 시각화 파이프라인 연결.
실제 영상을 통한 낙하 감지 정확도 및 시각화 위치 검정.
고려 사항 및 잠재적 문제점 (Risk Analysis)
TrackNet 검출 누락: 셔틀콕이 바닥에 닿는 순간 속도가 빨라지거나 형태가 일그러져 검출되지 않는 프레임이 발생할 수 있습니다. 이를 위해 **검출이 끊기기 직전의 위치를 보간(Interpolation)**하거나 마지막 유효 좌표를 유지하는 안전장치가 필요합니다.
노이즈 필터링: 선수의 발이나 라켓 등 셔틀콕과 유사한 물체를 오인하여 낙하로 판정할 수 있습니다. 이를 방지하기 위해 객체의 크기 변화나 궤적의 연속성을 검증하는 필터를 추가해야 할 수 있습니다.
카메라 렌즈 왜곡: 사용자가 상정한 4개의 점이 지면에 완벽히 밀착되어 있다는 가정 하에 Homography가 동작하므로, 카메라의 설치 높이와 각도에 따른 오차 범위를 고려해야 합니다.
향후 확장성 고려 (Module Design)
독립적인 감지 모듈: 낙하 감지 로직을 ShuttlecockLandingDetector 클래스로 분리하여 추후 다른 추적 모델(예: YOLO 등)로 교체하더라도 로직을 재사용할 수 있게 설계하겠습니다.
시각화 추상화: 미니맵 렌더링 기능을 템플릿화하여 추후 전코트(Full Court) 시각화로 확장하기 용이하게 구성하겠습니다.
계획에 대해 확인해주시면 **마일스톤 1(코트 좌표계 고도화 및 보정 로직)**부터 착수하도록 하겠습니다. 확인 부탁드립니다.
